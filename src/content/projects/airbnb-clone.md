### Project Overview
A comprehensive reproduction of the Airbnb platform, focusing on high-fidelity UI/UX and complex server-side operations. This project demonstrates proficiency in building modern, scalable web applications with a focus on user experience and data integrity.

### Key Features
- **User Authentication:** Secure sign-up, login, and profile management handled via **Clerk**.
- **Property Listings:** Detailed descriptions, photos, amenities, and pricing for hosts.
- **Search Functionality:** Complex filtering system by country, guest count, and room numbers.
- **Booking Management:** Integrated calendar for date range selection and reservation logic.
- **Image Processing:** Seamless upload and retrieval flow for high-resolution property images using **Cloudinary**.
- **Responsive Design:** Optimized for desktop, tablet, and smartphone using **Tailwind CSS**.

### Technical Deep Dive
The application leverages **Next.js 14 App Router** for efficient routing and server-side rendering. **Prisma** serves as the ORM, providing type-safe database access to **MongoDB**.

#### Challenges Overcome
- **State Management:** Handling complex booking states and search parameters across decoupled components.
- **Performance:** Optimized image delivery and server-side caching for faster listing loads.

### Results
- Successfully built a production-ready clone with **95% feature parity** with the original platform.
- Demonstrated advanced skills in fullstack architecture and modern React design patterns.
