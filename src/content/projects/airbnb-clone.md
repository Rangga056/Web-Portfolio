### Project Overview
A comprehensive reproduction of the Airbnb platform, focusing on high-fidelity UI/UX and complex server-side operations. This project demonstrates proficiency in building modern, scalable web applications with a focus on user experience and data integrity.

### Key Features
- **User Authentication:** Multi-provider secure sign-up and login handled via **Clerk** and **Kinde**.
- **Property Listings:** Comprehensive host dashboard for creating listings with descriptions, photos, amenities, and dynamic pricing.
- **Advanced Search:** Complex filtering system by country, guest capacity, and room configurations.
- **Map Integration:** Interactive location picking and property visualization using **Leaflet**.
- **Booking Management:** Integrated calendar logic for date range selection and reservation flows.
- **Payment Processing:** Secure transaction handling integrated with **Stripe**.
- **Responsive Design:** Fully optimized experience across desktop, tablet, and mobile using **Tailwind CSS** and **Shadcn UI**.

### Technical Deep Dive
The application leverages **Next.js 14 App Router** for cutting-edge routing and server actions. **Prisma** acts as the bridge between the application logic and multiple data sources including **MongoDB** and **Supabase (PostgreSQL)**.

#### Architecture Highlights
- **Server Components:** Maximizing performance by fetching data on the server and reducing client-side JavaScript.
- **Type Safety:** End-to-end type safety using **TypeScript** for both frontend components and database schemas.
- **UI Consistency:** Built with a customized design system leveraging **Shadcn UI** for accessible and polished components.
