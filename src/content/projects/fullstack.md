### The Challenge
The existing academic management workflows were fragmented, leading to inefficiencies in student and faculty data handling. The objective was to modernize the core system to improve operational speed and user experience.

### The Solution
I contributed to the fullstack development of the **Academic Information System (SIA)**.

1.  **Architecture:** Implemented a robust REST API using **Node.js** and **Express**.
2.  **Frontend:** Built high-performance, reusable UI components with **React** and **Tailwind CSS**.
3.  **Data Modeling:** Optimized **PostgreSQL** queries to handle large student datasets efficiently.
4.  **Security:** Integrated JWT-based authentication and role-based access control (RBAC).

### Results
- Improved system efficiency by an estimated **50%**.
- Streamlined data entry for academic staff, reducing processing time by hours.
- Delivered a responsive, modern interface accessible across all device types.
