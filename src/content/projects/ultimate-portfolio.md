### Project Overview
A high-fidelity, interactive portfolio designed as a functional **Integrated Development Environment (IDE)**. This project pushes the boundaries of web-based shells, providing a seamless navigation experience that mimics a professional developer workspace.

### ✨ Key Features
- **VS Code Inspired Shell:** A complete IDE interface featuring an activity bar, sidebar, editor area, and status bar.
- **Interactive Terminal:** A functional command-line interface with custom commands (`help`, `ls`, `open`, `git status`) and command history.
- **Dynamic Tab System:** Multi-buffer management allowing users to open and switch between Markdown, JSON, and Code files.
- **Command Palette:** Quick-access navigation tool (`Cmd+K` / `Ctrl+K`) for searching and opening files across the workspace.
- **Multi-Theme Engine:** Real-time theme switching (Tokyo Night, Catppuccin, Gruvbox, Nord, Midnight) with persistent storage.
- **Intelligent Renderers:** Custom components for beautiful Markdown rendering, interactive JSON dashboards, and PDF visualization.
- **Mobile-First Responsiveness:** A complex desktop layout that intelligently collapses into a functional mobile drawer system.

### 🛠️ Technical Implementation
Built with the latest **React 19** and **Next.js 15**, utilizing the App Router for optimal performance and server-side logic.

#### Architecture Highlights
- **Context-Driven State:** Global shell state management via `ShellContext` for synchronized UI updates.
- **Framer Motion Orchestration:** Smooth, spring-based animations for sidebars, terminals, and tab transitions.
- **Tailwind CSS 4:** Leveraging the latest CSS-in-JS capabilities for a highly optimized and performant styling layer.

### Results
- Successfully created a unique developer-centric portfolio that demonstrates deep expertise in React ecosystem and complex UI architecture.
- Achieved high performance scores through efficient component decoupling and server-side rendering strategies.
