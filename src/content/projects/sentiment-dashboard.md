### Project Overview
An interactive dashboard for analyzing and visualizing sentiment trends in text data. This tool provides insights into public opinion and customer feedback through automated NLP processing.

### Key Features
- **Real-time Analysis:** Process user-supplied text or uploaded datasets instantly.
- **Visual Trends:** Dynamic charts showing sentiment distribution (Positive, Negative, Neutral).
- **Keyword Extraction:** Identifies core topics and themes from the analyzed text.
- **Custom Filters:** Filter results by date, category, or sentiment score.

### Technical Deep Dive
Built using **Python** and **Streamlit** for rapid development and deployment. The core sentiment analysis is powered by the **NLTK** library, using pre-trained models for accurate scoring. **Pandas** is used for efficient data manipulation and cleaning.

### Results
- Created a high-utility tool for marketing and customer service teams.
- Optimized processing speed to handle datasets with 10,000+ entries in under 5 seconds.
